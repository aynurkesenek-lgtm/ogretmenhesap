🗄️ Supabase kurulum SQL'i

  1. Kopyala butonuna basın → Supabase → SQL Editor → New query → yapıştırın → Run.
  2. Authentication → Sign In / Providers → Email: "Confirm email" seçeneğini kapatın.
  3. Authentication → Users → Add user: e-posta rasyonelx@ogretmenhesap.app, şifre: belirlediğiniz öğretmen şifresi, "Auto Confirm User" işaretli.
  4. Project Settings → API: Project URL ve anon / publishable anahtarı bana iletin (secret / service_role anahtarını paylaşmayın).
